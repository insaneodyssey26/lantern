# Security Policy

## Supported Versions

We release security updates and patches for the latest active release branch of Lantern.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of our users seriously. If you discover a security vulnerability or DNS leak in Lantern, please report it responsibly:

### How to Report

1. **Privately via GitHub**: Use GitHub's [Private Vulnerability Reporting](https://github.com/insaneodyssey26/lantern/security/advisories/new) feature on this repository.
2. **Direct Contact**: If private reporting is unavailable, reach out to the project maintainer at `skmasumali.main@gmail.com` with the subject `[SECURITY] Lantern Vulnerability Report`.

Please include:
- A description of the vulnerability and its potential impact.
- Steps or a proof-of-concept to reproduce the behavior.
- The Android version and device model tested.

### What to Expect

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will coordinate an investigation, provide updates on the fix, and release an update before public disclosure.
- We kindly ask that you do not publicly disclose the vulnerability until a patch has been published to protect active users.
